# 個人網頁／推甄作品摘要

## TKU Atlas：淡水生活互動地圖

TKU Atlas 是以淡江大學生活圈為起點的互動地圖作品，整合地點分享、分類探索與「吃什麼？」選餐轉盤，並將可放置範圍擴展至完整淡水區。

專案使用 React、TypeScript、MapLibre 與 Supabase，實作地圖互動、Google 登入整合、資料保存、地點所有權與圖片流程。開發重點包括前端／資料庫一致的地理驗證、原子資料寫入、手機操作與可重現的測試。採 AI 輔助開發，並保留測試與除錯證據。

截至 2026-10-03，77 項單元、資料庫與瀏覽器測試案例在成功批次中通過，包含真實 HTTPS 網站驗證。完整雙帳號雲端整合、圖片上傳刪除與實體手機測試仍待完成。
